# billionaires-emissions

This repo contains the code required to reproduce the empirical analyses presented in

The Carbon Content of Billionaire Wealth: Composition, Concentration, and Taxation

by Krystian Bua, Matteo Coronese, Francesco Lamperti, Chiara Marino, Elisa Palagi, and Andrea Roventini.

Repository structure

data/
    example_data.csv

scripts/
    generate_example_data.R
    main.R
    residence_nationality.R
    robustness_public.R
    robustness_tax_only_public.R
    robustness_tax_emission_intensity.R
    robustness_tax_topup.R

charts/
    Figures generated by the scripts

Data availability

The empirical analysis in the paper relies on data obtained from the Bloomberg Billionaires Index and Refinitiv, which cannot be redistributed.

To facilitate code inspection and reproducibility, this repository includes an artificial example dataset (data/example_data.csv) together with the script used to generate it (scripts/generate_example_data.R).

The example dataset reproduces the structure, variable names, data types, and logical relationships of the original database but contains entirely synthetic values. It is provided solely to illustrate the data structure and to allow users to execute the analysis scripts.

Running the code

The scripts are intended to be executed from the project root directory.

The main empirical analysis can be reproduced by running

source("scripts/main.R")

Additional scripts reproduce the robustness analyses and supplementary figures reported in the paper.

Software

The analysis was conducted in R (version 4.4.2).

Required packages are loaded directly within each script.
